# v0.1 实现计划

## 范围

从空仓库完成 issue #1 的 v0.1 文件。只支持简体中文技术文档和对话回复。
后续版本的评测、200 条词典、插件、营销模式不在本次范围内。

## 实现

1. 编写规范全文：42 条规则、三层适用范围、两种模式、计数方法、词典种子分组。
2. 编写不足 3000 字的技能：基础层、文档 12 条、回复 6 条、改写与检查流程。
3. 编写词语替换、4 类使用场景、完整系统提示和约 150 字短版。
4. 提供 8 组示意改写与手动试写记录要求。没有真实模型输出时不得冒充真实案例。
5. 编写 README、MIT 许可和无依赖本地构建脚本。构建从规范生成可独立安装的规则目录与技能归档。

## 一致性与安全

规范全文是规则唯一编辑源；构建生成技能内完整副本，避免安装后引用仓库外文件。
事实、数字、代码、错误原文、安全警告、操作确认和不确定性优先于文字规则。
v0.1 严格模式执行字数等约束，但不宣称已完成第 1.7 条的完整词典合规检查。

## 验证

只运行本地构建：检查条号、核心技能长度和资源链接，生成独立 ZIP 与校验摘要。
不执行测试、模型试写或收费 API 请求，不配置 GitHub Actions。
真实 DeepSeek/GPT 的 8 场景手动试写留待用户执行，不捏造性能数字。
